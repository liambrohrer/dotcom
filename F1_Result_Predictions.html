# Columns for which to create lag-1 variables
lag_columns = [
    'grid',
    'positionOrder',
    'driver_points_per_round',
    'driver_wins_per_round',
    'constructor_points_per_round',
    'constructor_wins_per_round'
]

# Create lag-1 variables for each driver
for driver_id, df in driver_data.items():

    # Sort observations chronologically by raceId
    df.sort_values('date', inplace=True)

    # Create lag-1 variables
    for col in lag_columns:
        df[f'{col}_lag1'] = df[col].shift(1)

# Columns to retain for prediction
selected_columns = [
    'resultId',
    'raceId',
    'date',
    'driverId',
    'constructorId',

Fitting Gradient Boost Regression¶

  • Squared error used for gradient boost fitting
  • Uses grid search minimizing MAE for hyperparameter selection
  • MAE is used for interpretability (score = number of positions between predicted and actual result)
  • Grids have been reduced to the previously computed best hyperparameters to save runtime

Model Performance¶

These results suggest that our prdictions will be about six positions off on average, but with significant variability in our uncertainty. The high variability of MAE could be due to the nature of formula 1, where better teams are often more consistent, making higher finishing positions more predictable than those lower down.

The level of accuracy seems fairly consistent with what you would get from an average F1 fan. This is not suprising as the predictors used are very simple. This results in the model picking up on much of the easily explainabled variability, but needing additional useful predictors to generate any significantly interesting insights.
